# Rules for every agent in this repo

## Hard rules

1. **Nothing posts from here.** The publisher writes `queue.md`; Zaal approves; only then does it go to the social queue. ZAO X posting is paused since 3 Nov 2026 until Zaal says go.
2. **No AI label in content.** Never write "made with AI", "AI voice", "generated by" into a caption, reel, recap or description.
3. **Only sourced facts.** Every number names its source and date (wavewarz.info stats, ZM, ZAOresearch). Round down. If it cannot be sourced, cut it.
4. **No private material.** Meetings in ZM `docs/meetings-log.md` stay private. No chat screenshots, no finance, no personal moves.
5. **Credit first.** Artists and guests are named before The ZAO in every recap and post.
6. **No em dashes** in anything that will be published. Hyphens, commas or periods.
7. **ZM is the source of truth.** If an item is missing from ZM, log it there first (its README has three ways), then make it here.

## Canonical spellings

The ZAO, ZAOstock, WaveWarZ, ZOL bot, ZABAL Games, COC Concertz, Better Call Zaal, BCZ YapZ, SongJam, Magnetiq, RewindZ, PlugZ, Sparkz. Social posts open with **ZM**.

| Posts (Farcaster, X, TG, Discord) | open with ZM, what was built or said, no hashtags, no emojis | ZM brand kit |

## Working rules

- One item at a time. Everything for one ZM item goes in `out/<slug>/`.
- Read the transcript or the ZM page before writing. Never write from the title alone.
- Status at the top of every file in `out/`: `draft`, `approved`, or `queued`.
- Keep it light: no video renders or transcription from this repo; those run in zao101-reels and spaces-recap, one at a time.
